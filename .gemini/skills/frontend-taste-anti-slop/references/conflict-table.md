## 2. Genuinely Additive Anti-Slop Practices Retained

1. **Anti-Slop Copy & Authenticity**: Eliminate filler buzzwords, invented metrics/testimonials/logos, leftover sample tags, and dead `href="#"` links; enforce consistent action wording, verb + object CTAs, and concrete empty/error microcopy.
2. **Surface & Visual Discipline**: Cap container nesting at `<= 2` box levels; require every visual (`<img>`, `<svg>`, chart) to render cleanly with explicit dimensions (`CLS = 0`) and zero text baked into images.
3. **Pointer & Micro-Interaction Precision**: Guard hover-only animations behind `@media (hover: hover) and (pointer: fine)` with keyboard `:focus-visible` parity, crisp `:active` press feedback, and `>= 16px` mobile input sizing.
4. **Screen-by-Screen Structural Discipline**: Enforce exactly one visible `<h1>` per routed page, equal left/right content edges, zero `375px` horizontal overflow, and `>= 44x44px` touch targets.
